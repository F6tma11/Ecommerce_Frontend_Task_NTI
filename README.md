# CozyCart — Vanilla JavaScript E-Commerce

A learning project built with HTML, CSS, Vanilla JavaScript and Local Storage. No ready-made theme is used.

## Features
- Customer registration, login and logout
- Demo admin account and admin creation
- Product and category CRUD with validation
- Product search, category filtering and sorting
- Wishlist and shopping cart saved in Local Storage
- Checkout creates a PENDING order
- Admin can confirm/reject orders and view all orders
- Customer can view previous orders
- Responsive layout

## Run locally
1. Download or clone this repository.
2. Open `index.html` in a browser, or use VS Code Live Server.
3. Demo admin login: `admin@cozycart.com` / `Admin123!`

## Reset demo data
Open browser DevTools → Application/Storage → Local Storage and remove keys starting with `cozycart_`, then refresh.

## Important limitations
Local Storage is not a secure database. Passwords and roles can be read/modified by the browser user. Do not use real credentials or deploy this as a production store. PayPal Sandbox, ratings, and returns are not implemented in this starter version.
